# Customer Data Cleaning & Preprocessing Using Python

## Overview

This project focuses on cleaning and preprocessing a customer dataset using Python. The goal was to identify and resolve common data quality issues and prepare the dataset for further analysis.

## Dataset

* 10200 customer records
* 12 columns
* Customer demographic, purchase, feedback and date related information

## Data Cleaning Steps

* Inspected dataset structure and statistics
* Identified and handled missing values
* Cleaned inconsistent Age values
* Standardized Gender, City, and Country values
* Removed duplicate records and duplicate Customer IDs
* Corrected data types
* Detected and removed outliers using Z-score
* Exported the cleaned dataset as a CSV file
